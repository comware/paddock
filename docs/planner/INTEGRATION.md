# Planner Module Integration Guide

This document explains how the Planner module integrates with Grow and Propagation modules, focusing on how PlannerEvents link to trays and batches.

---

## Overview

The Planner module serves as a **coordination layer** across Paddock's growing modules. It provides:

1. **Manual Events**: User-created calendar entries
2. **Auto-Generated Events**: Computed from tray/batch lifecycle data
3. **Entity Linking**: Navigation between calendar and module entities

## Entity Relationships

### PlannerEvent Links

A PlannerEvent can link to **at most one** of:
- A GrowTray (`trayId`)
- A PropBatch (`batchId`)

It **always** has:
- A GrowSite (`siteId`) - required
- Optionally a PropStation (`stationId`)

```typescript
// Valid: Event linked to tray
{
  id: "evt-001",
  title: "Harvest Sunflower Tray #42",
  siteId: "site-001",
  trayId: "tray-042",      // ✓ Linked to tray
  batchId: undefined,       // ✓ No batch link
}

// Valid: Event linked to batch
{
  id: "evt-002",
  title: "Check rooting - Lavender Batch 2026-015",
  siteId: "site-001",
  stationId: "station-002",
  trayId: undefined,
  batchId: "batch-015",     // ✓ Linked to batch
}

// Valid: Unlinked event
{
  id: "evt-003",
  title: "Order seeds for spring",
  siteId: "site-001",
  trayId: undefined,
  batchId: undefined,       // ✓ No links - general event
}

// INVALID: Cannot link to both
{
  trayId: "tray-042",
  batchId: "batch-015",     // ✗ Not allowed
}
```

## Integration with Grow Module

### Linked Fields

| PlannerEvent Field | GrowTray Field | Purpose |
|--------------------|----------------|---------|
| `siteId` | `siteId` | Must match (same site) |
| `trayId` | `id` | Foreign key to tray |
| `speciesId` | via `variety` | Link to GrowVarietyConfig |

### Auto-Generated Events from Trays

The Planner computes calendar events from tray lifecycle data:

#### Blackout → Light Event

**Source**: `GrowTray.dateToLight` (computed from `dateSown` + `blackoutDays`)

```typescript
// When tray is in blackout phase with pending light date
if (tray.status === 'blackout' && tray.dateToLight) {
  yield {
    title: `Move to light: ${tray.variety} #${tray.trayNumber}`,
    eventType: 'blackout_end',
    scheduledDate: tray.dateToLight,
    siteId: tray.siteId,
    trayId: tray.id,
    isAutoGenerated: true,
    sourceType: 'tray',
    sourceId: tray.id,
  };
}
```

#### Harvest Event

**Source**: Computed from `GrowVarietyConfig.typicalDaysToHarvest`

```typescript
// When tray is in light phase
if (tray.status === 'light' && tray.dateToLight) {
  const config = getVarietyConfig(tray.variety);
  const harvestDate = addDays(tray.dateToLight, config.typicalDaysToHarvest - config.defaultBlackoutDays);

  yield {
    title: `Harvest: ${tray.variety} #${tray.trayNumber}`,
    eventType: 'harvest',
    scheduledDate: harvestDate,
    siteId: tray.siteId,
    trayId: tray.id,
    isAutoGenerated: true,
    sourceType: 'tray',
    sourceId: tray.id,
  };
}
```

### Navigation: Event → Tray

When user clicks a tray-linked event:

```typescript
function handleEventClick(event: PlannerEvent) {
  if (event.trayId) {
    // Navigate to tray detail view
    navigate(`/grow/trays/${event.trayId}`);
  }
}
```

### Navigation: Tray → Events

Tray detail view can show linked events:

```typescript
// In TrayDetail component
const linkedEvents = usePlannerEvents(state =>
  state.getEventsByTray(trayId)
);

// Display timeline of events related to this tray
```

## Integration with Propagation Module

### Linked Fields

| PlannerEvent Field | PropBatch Field | Purpose |
|--------------------|-----------------|---------|
| `siteId` | `siteId` | Must match |
| `stationId` | `stationId` | Current station location |
| `batchId` | `id` | Foreign key to batch |
| `speciesId` | via `species` | Link to PropSpeciesConfig |

### Auto-Generated Events from Batches

The Planner computes calendar events from batch stages:

#### Rooting Check Event

**Source**: `PropBatch.dateTaken` + `PropSpeciesConfig.typicalRootingDays`

```typescript
// When batch is in 'taken' or 'rooting' stage
if (['taken', 'rooting'].includes(batch.stage)) {
  const config = getSpeciesConfig(batch.species);
  const checkDate = addDays(batch.dateTaken, config.typicalRootingDays * 0.5);

  yield {
    title: `Rooting check: ${batch.species} ${batch.batchNumber}`,
    eventType: 'rooting_check',
    scheduledDate: checkDate,
    siteId: batch.siteId,
    stationId: batch.stationId,
    batchId: batch.id,
    isAutoGenerated: true,
    sourceType: 'batch',
    sourceId: batch.id,
  };
}
```

#### Pot Up Reminder

**Source**: `PropBatch.dateRooted` + configurable delay

```typescript
// When batch is 'rooted' but not yet potted
if (batch.stage === 'rooted' && batch.dateRooted) {
  yield {
    title: `Ready to pot up: ${batch.species} ${batch.batchNumber}`,
    eventType: 'pot_up',
    scheduledDate: addDays(batch.dateRooted, 3), // 3-day buffer
    siteId: batch.siteId,
    stationId: batch.stationId,
    batchId: batch.id,
    isAutoGenerated: true,
    sourceType: 'batch',
    sourceId: batch.id,
  };
}
```

#### Hardening Reminder

**Source**: `PropBatch.datePottedUp` + species-specific timing

```typescript
if (batch.stage === 'potted_up' && batch.datePottedUp) {
  const config = getSpeciesConfig(batch.species);
  const hardenDate = addDays(batch.datePottedUp, config.daysToHarden || 14);

  yield {
    title: `Begin hardening: ${batch.species} ${batch.batchNumber}`,
    eventType: 'harden_off',
    scheduledDate: hardenDate,
    siteId: batch.siteId,
    batchId: batch.id,
    isAutoGenerated: true,
    sourceType: 'batch',
    sourceId: batch.id,
  };
}
```

#### Graduation Ready

**Source**: `PropBatch.dateReady` (when stage = 'ready')

```typescript
if (batch.stage === 'ready' && batch.dateReady) {
  yield {
    title: `Ready for sale/planting: ${batch.species} ${batch.batchNumber}`,
    eventType: 'graduation',
    scheduledDate: batch.dateReady,
    siteId: batch.siteId,
    batchId: batch.id,
    isAutoGenerated: true,
    sourceType: 'batch',
    sourceId: batch.id,
  };
}
```

## Auto-Event Lifecycle

Auto-generated events are **not persisted**. They're computed each time the calendar loads:

### Why Not Persist?

1. **Consistency**: When tray/batch data changes, events auto-update
2. **No Orphans**: Deleted trays/batches don't leave orphan events
3. **Simpler Sync**: No need to keep two data sources in sync
4. **Storage Efficiency**: No duplicate storage of computed data

### Distinguishing Auto vs Manual Events

```typescript
// In the store
function mergeEvents(): PlannerEventWithComputed[] {
  const manual = enrichEvents(rawEvents);
  const auto = generateAutoEvents(trays, batches);

  // Auto events have isAutoGenerated = true
  return [...manual, ...auto].sort(byScheduledDate);
}
```

### UI Treatment

| Aspect | Manual Events | Auto Events |
|--------|---------------|-------------|
| Editable | Yes | No (read-only) |
| Deletable | Yes | No |
| Completable | Yes | Syncs with source |
| Visual | Solid border | Dashed border |
| Icon | User icon | Auto/sync icon |

## Cross-Module Navigation Patterns

### From Calendar to Entity

```typescript
// CalendarEvent click handler
function navigateToSource(event: PlannerEvent) {
  if (event.trayId) {
    navigate(`/grow/trays/${event.trayId}`);
  } else if (event.batchId) {
    navigate(`/propagation/batches/${event.batchId}`);
  } else {
    // Open event detail modal
    openEventDetail(event.id);
  }
}
```

### From Entity to Calendar

```typescript
// TrayDetail.tsx
function TrayCalendarSection({ tray }: { tray: GrowTray }) {
  const events = usePlannerEvents(s => s.getEventsByTray(tray.id));

  return (
    <section>
      <h3>Scheduled Events</h3>
      <EventList events={events} />
      <Button onClick={() => openCreateEvent({ trayId: tray.id })}>
        Add Event
      </Button>
    </section>
  );
}
```

### Deep Linking

Support URL patterns for calendar with filters:

```
/planner                           # Default: current month
/planner?date=2026-03-15          # Go to specific date
/planner?tray=tray-042            # Filter to tray's events
/planner?batch=batch-015          # Filter to batch's events
/planner?site=site-002            # Filter by site
```

## Error Handling

### Orphaned References

When a linked entity is deleted:

```typescript
// Validation on event load
function validateEventLinks(event: PlannerEvent): PlannerEvent {
  if (event.trayId) {
    const tray = getTray(event.trayId);
    if (!tray) {
      // Tray was deleted - clear the link
      return { ...event, trayId: undefined };
    }
  }
  // Similar for batchId
  return event;
}
```

### Concurrent Edits

Since Paddock is single-user and local-first:
- No complex conflict resolution needed
- Last write wins for manual events
- Auto events always reflect current source data
