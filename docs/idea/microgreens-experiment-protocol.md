# Microgreens Experiment Protocol

## 6-Week Validation Sprint

**Purpose**: Answer the critical question: "Can I reliably grow quality produce, and do I enjoy doing it?"

**Investment**: $300-500 AUD
**Time Commitment**: 8-10 hours/week
**Space Required**: 2-3 square meters (corner of garage, spare room, or covered balcony)
**Decision Point**: Week 6 - Hell Yes or No?

---

## Why Microgreens First?

| Factor | Benefit |
|--------|---------|
| Fast feedback | 7-14 day seed-to-harvest vs months for vegetables |
| Low cost failure | $5-10 per failed tray, not $500 in crop loss |
| Year-round | No seasonal dependency - test anytime |
| High margin product | $20-40/kg retail - validates premium produce model |
| Skill transfer | Germination, watering, light, pest management apply to all growing |

**This experiment will reveal**: Your consistency, attention to detail, problem-solving ability, and genuine interest - the four factors that determine farming success.

## Week-by-Week Protocol

### Week 1: Setup & First Sow

**Goals**: Equipment ready, first 4 trays planted, daily routine established

**Day 1-2: Setup**
- [ ] Set up growing station (shelving, lights, power)
- [ ] Prepare coco coir - hydrate brick, let drain
- [ ] Label 4 trays with variety and date
- [ ] Position light 15-20cm above tray height

**Day 3: First Sowing**

| Tray | Variety | Seed Weight | Pre-soak? |
|------|---------|-------------|-----------|
| 1 | Sunflower | 80-100g | Yes - 8-12 hours |
| 2 | Pea shoots | 80-100g | Yes - 8-12 hours |
| 3 | Radish | 15-20g | No |
| 4 | Broccoli | 8-10g | No |

**Sowing Steps:**
1. Fill tray with 2-3cm moist coco coir, press flat
2. Spread seeds evenly - aim for dense but single layer (seeds touching, not piled)
3. Mist thoroughly with spray bottle
4. Cover with inverted tray (blackout dome)
5. Label: Variety / Date / Weight sown
6. Place in growing area (no light needed during blackout)

**Day 3-7: Blackout Phase**
- [ ] Check twice daily: mist if surface feels dry
- [ ] Lift dome to check germination progress
- [ ] Record observations in log

**Daily Time**: ~30 minutes

**End of Week 1 Checkpoint:**
- [ ] All 4 trays showing germination?
- [ ] Growing area functional?
- [ ] Daily routine established?

---

### Week 2: First Harvest & Analysis

**Goals**: Complete first growth cycle, harvest, assess quality, plant second batch

**Day 8-10: Light Phase**
- [ ] Remove blackout domes when seedlings are 2-3cm tall
- [ ] Position under grow light (16-18 hours light/day)
- [ ] Switch from misting to bottom watering (water in tray below)
- [ ] Watch for: yellowing, mold, leggy growth

**Day 10-14: Harvest Window**

Harvest when:
- Sunflower: Leaves fully open, before first true leaves
- Pea shoots: 10-15cm tall, tendrils forming
- Radish: First true leaves appearing, 5-7cm tall
- Broccoli: Deep green, cotyledons fully open, 5-7cm tall

**Harvest Steps:**
1. Water day before harvest (improves shelf life)
2. Cut just above soil line with sharp scissors
3. Weigh harvest immediately
4. Taste test! Note flavor, texture
5. Store in container with damp paper towel in fridge

**Week 2 Data Collection:**

| Metric | Tray 1 | Tray 2 | Tray 3 | Tray 4 |
|--------|--------|--------|--------|--------|
| Variety | | | | |
| Seeds sown (g) | | | | |
| Days to harvest | | | | |
| Harvest weight (g) | | | | |
| Yield ratio (harvest/seed) | | | | |
| Quality grade (A/B/C/F) | | | | |
| Problems observed | | | | |
| Would you sell this? Y/N | | | | |

**Quality Grading:**
- **A**: Uniform height, vibrant color, no defects - market ready
- **B**: Minor inconsistencies but sellable
- **C**: Edible but not sellable - family consumption
- **F**: Failed - mold, damping off, didn't germinate

**Day 12-14: Second Batch**
- [ ] Sow 4 more trays (same varieties)
- [ ] Apply lessons from first batch

**End of Week 2 Checkpoint:**
- [ ] At least 2 of 4 trays produced edible harvest?
- [ ] Yield ratio calculated for each variety?
- [ ] Problems identified and hypotheses formed?

### Week 3-4: Iteration & Troubleshooting

**Goals**: Improve on first batch, test variables, establish succession rhythm

**Experiments to Run (choose 2):**

| Experiment | Method | What You'll Learn |
|------------|--------|-------------------|
| Seed density | Same variety, 2 trays: 1x density vs 1.5x density | Optimal seeding rate |
| Blackout duration | Same variety: 3 days vs 5 days blackout | Best germination approach |
| Growing medium | Coco coir vs soil-based mix | Medium preference |
| Watering frequency | Bottom water daily vs every 2 days | Moisture management |

**Succession Planting Schedule:**

| Week | Mon | Thu |
|------|-----|-----|
| 3 | Sow 2 trays | Sow 2 trays |
| 4 | Sow 2 trays | Sow 2 trays |

This creates a continuous harvest pipeline.

**Daily Routine (Week 3-4):**
- Morning (20 min): Check all trays, water as needed, move between blackout/light
- Evening (10 min): Quick check, record observations
- Harvest days (30 min): Cut, weigh, store, clean trays

**Troubleshooting Guide:**

| Problem | Likely Cause | Fix |
|---------|--------------|-----|
| White fuzzy mold | Overwatering + poor airflow | Reduce water, add fan, increase spacing |
| Seeds not germinating | Old seeds, wrong temp, too dry | Fresh seeds, 18-24°C, mist more |
| Leggy/pale growth | Insufficient light | Lower lights, increase hours |
| Falling over (damping off) | Fungal disease from overwatering | Start fresh, sterilize trays, reduce water |
| Uneven germination | Uneven seed distribution or moisture | Spread more carefully, mist evenly |
| Yellowing leaves | Overwatering or harvest too late | Reduce water, harvest earlier |
| Bitter taste | Harvest too late, heat stress | Harvest younger, check temperature |

**End of Week 4 Checkpoint:**
- [ ] Consistent harvests happening?
- [ ] At least one variety achieving 80%+ success rate?
- [ ] Time per week tracking at 8-10 hours or less?
- [ ] Still enjoying the process?

## Go/No-Go Decision Framework

### Hell Yes Criteria (ALL must be true)

- [ ] **Competence**: >75% of harvests were market quality (Grade A or B)
- [ ] **Consistency**: Last 2 weeks had zero failed trays
- [ ] **Enjoyment**: Personal fit score >36/60
- [ ] **Economics**: Gross margin >$5 per tray achievable
- [ ] **Time**: Actual time was within 20% of target
- [ ] **Family**: Household supportive of scaling up

### Decision Matrix

| Competence | Enjoyment | Economics | Decision |
|------------|-----------|-----------|----------|
| High | High | Works | **GO** - Proceed to Phase 2 |
| High | Low | Works | **PAUSE** - Can you hire help for tasks you dislike? |
| Low | High | Works | **EXTEND** - More practice needed, but you've got the drive |
| Low | Low | Works | **STOP** - Wrong venture for you |
| Any | Any | Broken | **PIVOT** - Different crop selection or model needed |

## Quick Reference Cards

### Daily Checklist

**Morning (15-20 min)**
- [ ] Check blackout trays - mist if dry
- [ ] Check light trays - bottom water if needed
- [ ] Rotate trays 180° (even light exposure)
- [ ] Look for problems: mold, pests, yellowing
- [ ] Harvest any ready trays

**Evening (5-10 min)**
- [ ] Quick moisture check
- [ ] Update experiment log
- [ ] Plan tomorrow's tasks

### Variety Quick Reference

| Variety | Soak | Blackout | Total Days | Yield |
|---------|------|----------|------------|-------|
| Sunflower | 8-12hr | 3-4 days | 10-14 | 150-250g |
| Pea | 8-12hr | 3-4 days | 10-14 | 150-200g |
| Radish | No | 2-3 days | 6-10 | 100-150g |
| Broccoli | No | 3-4 days | 8-12 | 80-120g |

### Optimal Conditions

| Factor | Range | Notes |
|--------|-------|-------|
| Temperature | 18-24°C | Below 15°C = slow; above 28°C = problems |
| Light hours | 16-18/day | Use timer for consistency |
| Light distance | 15-25cm | Closer = stockier growth |
| Humidity | 50-70% | Fan if too humid |
| Watering | Keep moist, not wet | Overwatering is #1 killer |

## Final Note

**This experiment costs $300-500 and 50-60 hours to answer a $100,000 question.**

The research says the market exists and the numbers work. What's unknown is whether YOU can execute and whether YOU want to. Six weeks of deliberate practice will tell you more than six months of additional planning.

If it's a "Hell Yes" - you'll know.
If it's not - you'll have saved yourself from a costly mistake.

Either outcome is a win.
